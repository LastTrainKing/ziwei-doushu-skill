# 紫微斗数解读参考

配合 `scripts/chart.ts` 的输出使用。这里只写解读时需要的结构性知识，不替代命盘数据。

## 一、十二宫主管

| 宫位 | 主管 | 对宫 | 解读要点 |
|---|---|---|---|
| 命宫 | 本性、格局高低、一生基调 | 迁移 | 全盘核心，先定命宫再谈其他 |
| 兄弟 | 手足、平辈、合作搭档 | 仆役 | 也看合伙关系与同辈助力 |
| 夫妻 | 配偶特质、婚姻状态 | 官禄 | 男命兼看事业助力，女命兼看自身能力投射 |
| 子女 | 子嗣、晚辈、下属、创作 | 田宅 | 也看桃花与合伙投资 |
| 财帛 | 求财方式、现金流 | 福德 | 重点在「怎么赚」，不是「有多少」 |
| 疾厄 | 体质、易患病部位 | 父母 | 配合五行局与煞星看 |
| 迁移 | 外出、异地、社交印象 | 命宫 | 命宫的对宫，外出表现常与本性相反 |
| 仆役 | 朋友、下属、群众基础 | 兄弟 | 也叫交友宫 |
| 官禄 | 事业方向、职业性质 | 夫妻 | 也叫事业宫 |
| 田宅 | 不动产、家庭、财库 | 子女 | 积蓄能力看这里 |
| 福德 | 精神享受、兴趣、寿元 | 财帛 | 也叫福德宫，看心态与晚年 |
| 父母 | 父母、长辈、上司、文书 | 疾厄 | 也看学历与庇荫 |

**三方四正**：本宫 + 对宫 + 两个三合宫（相隔四宫）。判断任何一宫都不能只看本宫。

**空宫**：本宫无主星时借对宫主星看，力量约打七折，且更受对宫影响。

## 三、六吉六煞

- **六吉**：左辅、右弼（助力、人缘）、文昌、文曲（才华、文书）、天魁、天钺（贵人）
- **六煞**：擎羊（刚烈、外伤）、陀罗（拖延、纠缠）、火星（急躁、突发）、铃星（阴火、隐忍爆发）、地空、地劫（落空、破财）
- 煞星不全是不好：入庙或与吉星同宫时，常转化为冲劲与突破力

## 四、四化含义

| 四化 | 本质 | 落到宫位的表现 |
|---|---|---|
| 化禄 | 增益、缘分、财源 | 该宫领域顺遂、有资源、想投入 |
| 化权 | 掌控、责任、扩张 | 该宫领域要扛事、有主导欲、易争 |
| 化科 | 名声、文书、贵人 | 该宫领域体面、有口碑、易被看见 |
| 化忌 | 执着、亏欠、阻碍 | 该宫领域放不下、易反复、是功课所在 |

- **生年四化**：先天带来的，一生都在作用
- **大限四化**：这十年的主题，叠加在生年四化之上
- **自化**：宫干让本宫星曜自己化出，代表「自己把力量泄掉」或「自我消耗」

## 五、常见格局（脚本已自动判定，此处只作补充理解）

| 格局 | 构成 | 含义 |
|---|---|---|
| 紫府同宫 | 紫微天府同宫 | 稳重有依靠，富贵需会吉 |
| 杀破狼 | 七杀破军贪狼会命 | 变动开创，宜闯不宜守 |
| 武贪格 | 武曲贪狼会命 | 三十岁后发，宜金融销售 |
| 日月并明 | 太阳太阴庙旺会照 | 名声与实利兼得 |
| 机月同梁 | 天机太阴天同天梁会命 | 宜公职、企划、文职 |
| 巨日同宫 | 巨门太阳同宫 | 口才生财，宜教育传媒 |
| 府相朝垣 | 天府天相夹辅命宫 | 稳健有靠，宜管理 |
| 火贪/铃贪 | 火星或铃星与贪狼同宫 | 暴发格，起伏也大 |

判断格局要看**庙旺利陷 + 三方四正吉煞**，单颗星不成格。

## 六、大限与流年怎么看

1. **大限**：先看大限宫位本身（主星、四化），再看它的三方四正
2. **大限四化**：化禄入哪宫 → 这十年资源在哪；化忌入哪宫 → 这十年功课在哪
3. **流年**：流年干支对应宫位，看该宫星曜 + 该宫的三方四正
4. **叠加原则**：大限定十年主题，流年定当年触发点；两者都指向同一宫位时，事件最明显
5. **不要一年一年算**：用户问「今年」就答今年，问「这几年」再展开

## 七、解读口吻示例

**好的写法**：
> **【事业格局】** 官禄宫破军坐守（庙），三方会七杀、贪狼，是典型杀破狼。这类配置不适合长期待在流程固定的岗位，越是有变动、要开疆拓土的事，越能发挥。35–44 岁走田宅宫（辛干），大限四化禄巨门、忌文昌，这十年财路来自「开口说话」——谈客户、做内容、讲课，但文书合约要格外小心。

**要避免的写法**：
> 你命里注定大富大贵，35 岁必有横财。（绝对化 + 无依据）
> 你的事业宫有破军，破军是耗星，所以你一定会破财。（恐吓 + 单向解读）

## 八、边界

- 不预测生死、灾祸的具体时间
- 不做疾病诊断，只提示「该宫位对应部位宜留意，有症状请就医」
- 不承诺投资、婚姻结果
- 命盘是概率倾向，不是判决书——每次解读结尾都要把选择权交回用户
