# 合盘参考（倪海厦体系 + 《紫微斗数全书》）

配合 `scripts/heming.ts` 的输出使用。脚本已经算好事实，这里讲怎么读。

## 一、五步法（按顺序走，别跳步）

1. **命格基础**：双方命宫格局是否般配。警戒：双方皆杀破狼（两虎相争）、或一强一弱过度悬殊
2. **双宫联参**：夫妻宫 + 福德宫一起看
3. **夫妻宫互参**：甲夫妻宫主星是否对应乙命宫主星，反之亦然
4. **四化飞化**：双方生年化忌是否飞入对方命宫/夫妻宫
5. **大限同步**：双方当前大限的吉煞结构，是否同一节奏

## 二、双宫联参（最重要）

> 倪师原话：「看婚姻，光看夫妻宫，大错特错，一定要同时看福德宫。」

- **夫妻宫**：配偶的星性、外形、性格、互动模式——「对方是什么样的人」
- **福德宫**：深层感情、婚姻能否长久——「这段关系撑不撑得住」

典型断法：夫妻宫很好、福德宫很烂 → 散。所以脚本输出里福德宫主星一定要读。

## 三、天作之合的三级判定

| 级别 | 条件 | 说明 |
|---|---|---|
| 天作之合 | 甲夫妻宫主星 = 乙命宫主星 **且** 乙夫妻宫主星 = 甲命宫主星 | 双向对应，命中注定型 |
| 次级良配 | 只有单向对应 | 一方天然符合另一方的配偶期待 |
| 需另找依据 | 无对应 | 从命格互补、四化飞化、福德宫看 |

脚本「一、夫妻宫互参」直接给结论，照抄即可。

## 四、缘分类型（看四化引动）

| 类型 | 特征 | 表达分寸 |
|---|---|---|
| 化禄引动 | 正缘，感情顺遂有增益 | 可以直接说「缘分偏正」 |
| 化权引动 | 主动争取，有张力也有主导方 | 提示「谁更主动、谁在扛」 |
| 化科引动 | 和谐体面，互相尊重 | 适合长期相处型 |
| 化忌引动 | 逆缘/冤家，彼此牵挂但磨人 | **不要说「孽缘」吓人**，讲「相处成本高，需要主动调整」 |
| 双方互化忌 | 强烈但痛苦并存 | 强调「磨合空间」而非「注定失败」 |

## 五、婚期判断三层法

1. **本命**：夫妻宫无煞 → 宜早婚；有煞无吉 → 宜晚婚（男 30+、女 27+）；武曲/廉贞/七杀/破军在夫妻宫 → 一律建议晚婚
2. **大限**：大限夫妻宫吉星多 → 该十年有结婚机会；大限化忌 → 该十年感情受阻
3. **流年**：红鸾天喜入命宫或夫妻宫、流年宫位落到夫妻宫、流年三合方桃花星汇集

各宫位对应的结婚情形：夫妻宫（正常发展）、命宫（自己主动）、子女宫（奉子成婚）、田宅宫（因家庭房产）、父母宫（长辈介绍）。

## 七、事业合作合盘

- 看 **官禄宫**（事业方向是否兼容）、**兄弟/仆役宫**（合伙关系）、**福德宫**（能否同甘共苦）
- 吉象：命宫互补（一谋一行）、一方官禄化禄飞入对方官禄、兄弟宫有禄存无化忌冲
- 凶象：双方化忌互冲官禄、对方命宫化忌飞入己方财帛（消耗钱财）
- 巨门在兄弟/仆役宫：倪师讲「跟朋友合伙会朋友变仇人」，提示合伙要白纸黑字

## 八、把「凶语」转成人话

古籍原话很重，直接转述会吓到人。处理公式：

1. **先讲成立条件**：「古籍讲的是廉贞与贪狼同宫且会煞——你这盘是廉贞天相，不构成」
2. **再讲倾向**：「感情起伏会大一些，主要在沟通节奏上」
3. **最后给动作**：「婚前多相处一段时间、把财务边界说清楚」

**永远不转述**：生死、重病、夭折、克夫克妻的具体灾祸时间。这些既无法验证，也超出命理该承担的责任。

## 九、输出结构建议

```
**【关系基调】** 一句话定性（结构判定 + 缘分类型）
**【双方性格互动】** 双方命宫主星带来的差异与摩擦点
**【夫妻宫与福德宫】** 双宫联参，配偶特质 + 关系能不能撑住
**【四化与缘分】** 化忌飞向哪里，这段关系的功课是什么
**【相处建议】** 3 条具体可执行的
```

结尾一句「仅供参考」，并把选择权交回用户。
